3 STEPS

  1. Describe — チャットにシナリオを自然言語で入力
  2. Compute — RISU がシナリオを構築し UXsim で実行
  3. Explore — 可視化・グラフを対話的に操作

EXAMPLES

  • 作る — 「単純なボトルネック道路を作って」
  • 作る — 「3×3 グリッドネットワーク」
  • 作る — 「東京駅周辺を OSM から取得」
  • 分析 — 「渋滞が発生する条件を教えて」
  • 分析 — 「結果を速度グラフで見せて」
  • 比較 — 「車線を 2 倍にして比較して」
  • 取込 — CSV サンプル をダウンロード して + ボタンで添付

KEYBOARD

  • Enter 送信 / Shift+Enter 改行
  • Ctrl+K 新しい会話
  • Esc モーダルを閉じる

CANVAS

  • ドラッグ — パン / ホイール — ズーム
  • 右下の ⟲ でカメラをリセット

DRAW MODES

  • LINK — 道路を混雑度で色分け（俯瞰）
  • VEHICLE — 個車をドットで表示（標準）
  • TRAIL — 個車＋過去フレームの軌跡
